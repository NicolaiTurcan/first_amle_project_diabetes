01 · The goal

Which mistake costs more?

Before modelling anything, the metric was chosen by asking what each error means for a patient. The answer makes recall (sensitivity) the primary metric, the same measure the original 1988 ADAP paper uses for clinical tests.

✕ False negative · costly

A missed diabetes case

The patient is told they are healthy and gets no treatment. Untreated diabetes leads to severe, long-term complications.

✓ False positive · acceptable

A false alarm

A healthy patient is flagged. A routine follow-up blood test clears it up. That costs time and money, not health.

02 · The data

768 patients, and zeros that aren't zeros

Female patients of Pima Indian heritage, aged 21+. The data is split 80/20 (stratified) before exploring it. A glucose level or BMI of 0 is impossible, so those zeros are missing values. They are filled with medians from the training set only, and the same medians are applied to the test set.

04 · Models

Beat the baselines, then fix the imbalance

Only 35% of patients have diabetes, so a plain model leans towards "healthy". Two fixes were tried: class_weight="balanced" and a lower decision threshold of 0.3, chosen on the training data. All models were scored once on the held-out test set.

05 · The decision threshold

Trading precision for recall

Logistic regression outputs a probability. Lowering the cut-off from 0.5 to 0.3 flags more patients: recall rises, precision drops slightly. The curve is computed on the training set, where the threshold was chosen, so the test set stays unseen.

07 · Takeaways

What I learned

  1. Pick the metric from the cost of mistakes.

    Accuracy hides missed cases. Recall makes them visible.

  2. Split first, then explore.

    Every statistic (medians, cut-offs, threshold) is learned on the training set only.

  3. Baselines keep you honest.

    The plain model barely beat a one-line glucose rule. The improvement came from handling the imbalance.

  4. The threshold is a product decision.

    Going from 0.5 to 0.3 lifts test recall from 50% to 80% for 11 more false alarms.
